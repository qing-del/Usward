# Usward 正式前端

`frontend/` 是 Vue 3 + TypeScript + Vite 应用，视觉参照 `static/UI` 的 HTML 交互预览。它使用后端 Session 和 `/api/v1` 接口，不读取或迁移预览的浏览器演示数据。

## 本地运行

需要 Node.js 24.15+（或 22.22.2+）、Java 21 和 MySQL 8.4。先按 [后端运行说明](../docs/backend-setup.md) 启动服务并创建账号；正式前端没有演示账号或注册入口。

```sh
cd frontend
npm ci
npm run dev
```

打开 <http://127.0.0.1:5173/>。Vite 将同源 `/api/v1` 请求代理到 `http://127.0.0.1:8080`，因此浏览器中的 Session Cookie 和 CSRF 请求保持同一站点。修改代理目标时更新 `vite.config.ts`。生产部署需在同一 HTTPS 站点下把 `/api/v1` 转发到后端，并将其它应用路由回退到构建产物的 `index.html`；生产环境设置 `USWARD_COOKIE_SECURE=true`。

## 当前功能

- 登录、退出、修改密码，以及昵称、头像、显示时区、通知收件邮箱设置。
- 私人记忆的服务端搜索、筛选、分页、详情、创建、编辑、归档、恢复、删除。
- 个人日历的日程、周、月、1–93 天范围查询，以及个人安排的创建、编辑、删除。
- 在「我的」生成、撤销、预览、接受或解除双人连接；新口令只在创建后的当前页面显示，刷新后仅可查看邀请有效期并选择撤销或重新生成。
- 连接后可开启本人忙闲共享，并为个人安排逐条选择是否公开标题；日历的「对方忙闲」只展示服务端脱敏的时间、状态和获准公开的标题。
- 私密承诺的服务端分页、筛选、详情、创建、编辑、完成、取消、重开和删除；可从自己的卡片或安排关联来源。
- 在记忆卡片、个人安排和进行中的承诺详情设置、重设或取消私人提醒；新建内容时也可附带设置，内容保存后提醒失败可以单独重试。
- 私人提醒清单支持内容类型、状态筛选及服务端分页；站内通知清单支持全部、未读、已读筛选、单条已读和按查询快照全部标为已读。
- “今天”通过一次 `/dashboard` 查询展示今日个人安排、到期承诺、最近一张记忆、前五条待触发提醒和快捷入口。顶栏展示后端返回的全量未读数，在页面重新可见时及可见期间每 60 秒刷新。

未接入的逐条内容分享、表达、邀约和邮件发送不会使用本地假数据展示。连接本身不会分享历史内容；未连接时忙闲共享不可开启，未标注的时间也不代表有空。邮箱设置可以保存，但后端尚未启用邮件能力，提醒表单的邮件选项不可用，也不承诺站外送达。记忆列表摘要没有正文，承诺列表摘要没有说明或完成记录，打开详情才请求这些内容。仅日期截止保留原时区；精确时间和提醒时间按账号时区输入，夏令时重复时间需选择偏移，不存在的当地时间不能提交。过去的提醒时间可以保存，之后由后端扫描处理。

后端 Flyway V2 会将存量个人安排的公开标题选择重置为关闭，并递增受影响安排的版本；建立或解除连接时也会清除双方旧的标题公开选择。重新连接后，需要逐条重新选择公开标题。

## 验证

```sh
npm test
npm run build
```

`npm run build` 包含 TypeScript/Vue 类型检查，产物写入 `frontend/dist/`。测试覆盖 CSRF、401/409、连接邀请和版本冲突、账号切换、忙闲开关及脱敏日历、列表分页、提醒与通知、首页聚合和夏令时转换。真实端到端验证需要运行中的 Java/MySQL 后端和两个独立账号：分别登录后确认私人数据隔离、连接口令只显示一次、刷新后仍能看到有效邀请元数据、忙闲与标题按开关可见、解除后旧内容立即失权、重连不继承旧标题授权，并确认到时通知唯一性。

本轮本机验证（2026-10-04）：`npm test` 的 16 个文件、59 个用例通过，`npm run build` 的类型检查与构建通过；使用临时模拟 `/api/v1` 在 320、768、1440 像素宽度检查了「我的」和日历忙闲视图，没有整页横向溢出，并检查了手机宽度的一次性口令与解除说明弹窗。浏览器未报告脚本错误。模拟接口不等于真实后端联调。本机缺少可用的 Java 运行时、MySQL 和 Docker，因此 Flyway V2、后端集成测试、两个真实账号的数据隔离与刷新持久化、解除后失权及重连后的标题隔离仍待在可运行后端的环境验证。
